43/**
44 * @brief Realize a Form on @p surface.
45 *
46 * Builds the buffer at the Form's capacity and topology, registers the
47 * element, syncs so the geometry function's bounds_hint and contains reach
48 * the Layer before the first frame, then runs the Form's interaction wiring.
49 *
50 * A bare GeometryFn converts to a Form, so this also serves as the simplest
51 * element construction path for a caller's own geometry.
52 *
53 * @tparam T MappedState value type.
54 * @param surface Canvas to register on.
55 * @param form Geometry, topology, capacity, and interaction.
56 * @param initial Starting value written into MappedState.
57 * @param project Optional T to float projection for outbound readers.
58 * @return Fully constructed Mapped<T>, wired.
59 */
60template <typename T>
61[[nodiscard]] Mapped<T> create(
62 Surface& surface,
63 Geometry::Form<T> form,
64 T initial,
65 std::function<float(T)> project = {})
66{
67 auto mapped = internal::atelier().create_element<T>(
68 surface.layer(), surface.window(),
69 std::move(form.geometry), std::move(initial),
70 form.topology, form.capacity, std::move(project));
71
72 mapped.sync(&surface.layer());
73
74 if (form.wire)
75 form.wire(surface.ctx(), mapped.element.id, mapped.state);
76
77 return mapped;
78}

80/**
81 * @brief Build a FormaBuffer, register it, construct a Mapped<T>, add the
82 * element to @p surface's layer, and register it with the
83 * application Bridge.
84 *
85 * Surface-accepting overload of create_element. Reads the layer and
86 * window from @p surface; everything else matches the existing
87 * (Layer&, Window) overload.
88 *
89 * After registration, one sync() is run so that bounds_hint and contains

97 * directly from the geometry function on construction. The geometry
98 * function remains the user's; the sync is the same one that runs every
99 * frame.

102 * @param surface Canvas to register the element on.
103 * @param geom Geometry function producing vertex bytes from T.
104 * @param initial Starting value written into MappedState.
105 * @param topology Primitive topology for the FormaBuffer.
106 * @param project Optional T -> float projection for outbound readers.
107 * @return Fully constructed Mapped<T> with element registered.
108 */

123 * text editing onto it in one call.
124 *
125 * The one-call convenience over TextField::place(), the same split
126 * Portal::Forma::create<T> already has with a bare Form<T>. This builds
127 * the buffer (create_buffer, which TextField.cpp itself may never call;
128 * see TextField.hpp) and delegates. Build the buffer and TextField by hand
129 * instead for anything needing a non-default buffer setup (a shared
130 * texture slot alongside a background quad, for instance).
131 *
132 * @p scrollable composes a second primitive in, the same way: false (the
133 * default) matches every prior call exactly, and @p bounds is the field's
134 * own region. True builds a plain Scrollable (Scrollable::place(), @p bounds
135 * as its viewport) and calls TextField::scrollable() instead of place(),
136 * the same composition test_text_input() (test_8.hpp) once wired by hand,
137 * now living at the TextField primitive level; this is only the one-call
138 * convenience over it. That Scrollable is local to this call and not
139 * returned, so no indicator is added and nothing else can be tracked into
140 * the same viewport. Build the Scrollable yourself and call
141 * TextField::scrollable() directly (or place() + Scrollable::track() by
142 * hand) for either of those.
143 *
144 * @param surface Surface whose window, layer, and context own the field.
145 * @param bounds NDC region for both hit testing and the text quad,
146 * or, when scrollable, the fixed clipped viewport.
147 * @param params Shared render params. A default-constructed one is
148 * allocated if null.
149 * @param initial_text Starting text. Cursor starts at its end.
150 * @param scrollable When true, wraps the field in a Scrollable viewport.
151 * @return Registered, wired TextField. Portal::Forma::destroy(surface,
152 * field.element_id) is sufficient to tear the whole thing down,
153 * scrollable viewport included when @p scrollable is true. No
154 * manual multi-id cleanup is needed.
155 */

157 Surface& surface,
158 Kinesis::AABB2D bounds,
159 std::shared_ptr<Portal::Text::PressParams> params = nullptr,
160 std::string initial_text = {},
161 bool scrollable = false);

163/**
164 * @struct Tend
165 * @brief The fourth member of the Collapsible/Scrollable/TextField family,
166 * for a bare Form<T> control.
167 *
168 * Configure with form/initial, then place(Surface&) - same as all three
169 * siblings, Tend never builds a Surface itself, it only ever wraps one the
170 * caller already has. place() can only call Portal::Forma::create(), never
171 * create_element(), so the wire-dropping mistake create_element<T>'s
172 * bare-GeometryFn overload allows is structurally unreachable through Tend.
173 *
174 * place() retains a copy of the Surface it was given in the surface member
175 * (cheap - Surface's own three fields are shared_ptrs, so the copy shares
176 * the same Layer/Context/window as the original), so ctx()/layer()/window()
177 * stay reachable afterward without holding a separate reference of your own.
178 *
179 * Accepting a SurfaceConfig or a window description directly, so a caller
180 * with nothing yet does not need to call create_surface() themselves first,
181 * is deliberately not this struct's job - that escalation belongs to a
182 * higher-level composer (a future Creator-level tend_forma), which can
183 * resolve either shape into a Surface via Atelier::create_surface's own two
184 * overloads and hand the result to place() same as any other caller would.
185 *
186 * place() alone stops at construction. bridge() and track() are what keep
187 * going without falling out of the chain into a separate statement:
188 *
189 * @code
190 * auto fader = Tend<float>{
191 * .form = Geometry::horizontal_fader(track, 0.04F),
192 * .initial = 0.5F,
193 * }.place(surface)
194 * .bridge().write(vega.Constant(0.5) | Audio[0]);
195 * @endcode
196 *
197 * @tparam T MappedState value type.
198 */
199template <typename T>
200struct Tend {
201 /// @brief Geometry, topology, capacity, and interaction. Consumed by place().
202 Geometry::Form<T> form;
203
204 /// @brief Starting value written into MappedState. Consumed by place().
205 T initial {};
206
207 /// @brief Populated by place(). The real, fully wired element.
208 std::optional<Mapped<T>> result;
209
210 /// @brief Populated by place() with a copy of the Surface it was given,
211 /// so ctx()/layer()/window() stay reachable afterward.
212 std::optional<Surface> surface;
213
214 /**
215 * @brief Realize form on @p target.
216 * @param target Canvas to register on. A copy is retained in surface.
217 * @return *this, with surface and result populated.
218 */
219 Tend& place(Surface& target)
220 {
221 surface = target;
222 result = Portal::Forma::create<T>(target, std::move(form), std::move(initial));
223 return *this;
224 }

226 /**
227 * @brief Bridge::Binding handle for result's element.
228 *
229 * Thin forwarder to Bridge::at(). It keeps the chain unbroken rather than
230 * requiring a separate Portal::Forma::bridge().at(...) statement after
231 * place(). Every real bind()/write()/unbind() overload lives on the
232 * returned Binding itself, unchanged. Nothing here duplicates them.
233 * Calls internal::atelier().bridge() rather than the public
234 * Portal::Forma::bridge() wrapper, since that free function is declared
235 * in Forma.hpp, which this file cannot include.
236 *
237 * @pre place() has been called.
238 * @return Binding handle, chainable into .bind(...)/.write(...).
239 */
240 [[nodiscard]] Bridge::Binding bridge()
241 {
242 return internal::atelier().bridge().at(result->state);
243 }

245 /**
246 * @brief Register result's element for scroll reflow in @p panel.
247 *
248 * Thin forwarder to Atelier::track<T>(). See its own doc for what the
249 * default (built when @p reposition is omitted) does and why it
250 * captures only independently-owned pieces of result, never a pointer
251 * back to Tend/result itself.
252 *
253 * @pre place() has been called.
254 * @param panel Scrollable to track into.
255 * @param layer Layer both panel and result's element were
256 * registered on.
257 * @param base_bounds result's current on-screen NDC bounds.
258 * @param reposition Called with the scrolled bounds on every scroll.
259 * Defaulted when empty; see Atelier::track<T>().
260 * @return *this.
261 */
262 Tend& track(
263 Scrollable& panel,
264 Layer& layer,
265 Kinesis::AABB2D base_bounds,
266 std::function<void(Kinesis::AABB2D)> reposition = {})
267 {
268 internal::atelier().track(panel, layer, *result, base_bounds, std::move(reposition));
269 return *this;
270 }
