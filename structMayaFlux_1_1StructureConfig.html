Detailed Description

API-side playground for a complete visible structure.

A StructureConfig accepts the concrete forms already present in the API, plus the required rendering destination. Exactly one source is selected by the eventual Creator consumer.

This type is not a library contract. It is the API experiment from which repeated, concrete arrangements may later earn class-level configuration.
