Generate a mesh from the graph of a function sampled on a grid, y = f(x, z).

heights holds one value per grid point, row-major, columns values along X for each of rows steps along Z. The surface is centred on center and spans extent in X and Z. Normals and tangents come from central differences of the heights, so they follow the surface and are never degenerate. The raw height is stored in each vertex's weight. UV runs (0, 1) at the first row and first column.

Use it where the data is already a table of values: a sound's recent blocks, an image's brightness, a spectrogram, a column of a file. The triangle indices depend only on the grid size and are reused between calls, so regenerating every frame costs one pass over the heights; large grids are filled in parallel.

Parameters
heightscolumns * rows values.
columnsGrid points along X. Minimum 2.
rowsGrid points along Z. Minimum 2.
extentWorld size in X and Z.
height_scaleMultiplier from a height to a world Y offset.
centerWorld position of the middle of the grid at zero height.
Returns
MeshData ready for TRIANGLE_LIST draw, empty and logged if the sizes disagree.
