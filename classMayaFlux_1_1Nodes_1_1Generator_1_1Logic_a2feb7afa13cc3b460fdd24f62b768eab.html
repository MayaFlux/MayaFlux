void MayaFlux::Nodes::Generator::Logic::add_input_node ( const std::shared_ptr< Node > &  node)

Appends a node whose output feeds the next input slot.

Parameters
nodeNode to read each sample

Applies in parallel input mode. Nodes fill slots 0 to n-1 in the order they were added, growing the slot count if needed. When more slots are declared than nodes, slot n receives the sample the node is driven with, for example a buffer sample from a LogicProcessor; with no nodes that sample goes to slot 0 as before. A node already processed this cycle is read, not run again.
