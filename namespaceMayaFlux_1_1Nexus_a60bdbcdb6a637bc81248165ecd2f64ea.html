MAYAFLUX_API void MayaFlux::Nexus::recenter_attachment ( Attachment &  attachment,
std::optional< glm::vec3 > &  position,
const std::optional< glm::quat > &  orientation

Read the buffer's geometry again and move the anchor to match.

The Agent stays where it is: its offset from the new anchor absorbs the difference. Blocks for a ComputeMeshBuffer, so call it off the graphics thread.

Parameters
attachmentAttachment to recenter.
positionPosition of the Agent. Set if empty.
orientationOrientation of the Agent, if it has one.
