10/**
11 * @class LogicProcessor
12 * @brief Digital signal processor that applies boolean logic operations to data streams
13 *
14 * LogicProcessor bridges Nodes::Generator::Logic nodes with the buffer processing system,
15 * enabling sophisticated digital signal manipulation through various modulation strategies.
16 *
17 * The processor's job is simple:
18 * 1. Iterate through buffer samples
19 * 2. Generate logic values (0.0 or 1.0) by calling the Logic node
20 * 3. Apply logic to buffer data using a modulation strategy
21 *
22 * All logic computation (threshold detection, edge detection, state machines, etc.)
23 * is handled by the Logic node itself. The processor only manages iteration and
24 * application of results.
25 *
26 * Use cases include:
27 * - Binary pattern detection in data streams
28 * - Digital control signal generation
29 * - Conditional data flow routing
30 * - Event triggering based on signal characteristics
31 * - Digital state machine implementation
32 * - Signal quantization and discretization
33 */

36 /**
37 * @enum ModulationType
38 * @brief Defines how logic values modulate buffer content
39 *
40 * These are readymade strategies for applying binary logic (0.0/1.0) to
41 * continuous audio data, providing common compositional primitives for
42 * logic-based signal processing.
43 */
44 enum class ModulationType : uint8_t {
45 REPLACE, ///< Replace buffer with logic values: out = logic
46 MULTIPLY, ///< Gate/mask buffer: out = logic * buffer (standard audio gate)
47 ADD, ///< Offset buffer: out = logic + buffer
48
49 INVERT_ON_TRUE, ///< Invert signal when logic is true: out = logic ? -buffer : buffer
50 HOLD_ON_FALSE, ///< Hold last value when logic is false: out = logic ? buffer : last_value
51 ZERO_ON_FALSE, ///< Silence when logic is false: out = logic ? buffer : 0.0
52 CROSSFADE, ///< Smooth interpolation: out = lerp(0.0, buffer, logic)
53 THRESHOLD_REMAP, ///< Binary value selection: out = logic ? high_val : low_val
54 SAMPLE_AND_HOLD, ///< Sample on logic change: out = logic_changed ? buffer : held_value
55
56 CUSTOM ///< User-defined modulation function
57 };

206 /**
207 * @brief Processes every sample as a word of bit streams, one node per bit
208 * @param bits Word width, 1 to 24; 0 turns it off
209 *
210 * Each sample becomes an offset binary word (Kinesis::Discrete::to_word) and
211 * every bit position runs through its own clone of the node, so each plane
212 * keeps its own state. Planes are presented to the node as 0.0 or 1.0 and
213 * the output bits are recombined into the sample, so the logic data is a
214 * value in [-1, 1] rather than a bit. With a parallel node and keys, plane j
215 * sees plane j of every key and of this buffer: bitwise word operations
216 * across channels. The clones are taken at the next block and again when
217 * the node is replaced or this is called.
218 */

221 /**
222 * @brief Treats the samples of a block as cells of an automaton
223 * @param radius Cells on each side that feed a cell
224 * @param generations Steps per block; 0 turns it off
225 * @param wrap Whether the block's ends meet, otherwise cells beyond them are 0
226 * @param memory Whether the block perturbs the previous result instead of replacing it
227 *
228 * Needs a parallel node. A cell is 1 when its sample is above zero, and the
229 * node is evaluated for every cell with 2 * radius + 1 slots, slot 0 the
230 * cell furthest to the right and the last slot the furthest to the left,
231 * so Wolfram's rule numbers work with `input_truth_table_state(3, rule)`.
232 * With memory the block's cells are XORed into the previous block's final
233 * generation, so the pattern evolves across blocks; use one processor per
234 * channel (clone) for that. The logic data is the final generation, 0 or 1.
235 */
236 void set_neighbourhood(size_t radius, size_t generations = 1, bool wrap = true, bool memory = false);
