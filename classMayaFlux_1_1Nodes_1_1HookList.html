Detailed Description

Stores, fires and clears the hooks of one node channel.

A HookList registers itself with the Node that owns it, so Node::remove_all_hooks and Node::unhook reach every list without any node class overriding them. Ids are unique within the owning node.

Reading and writing are safe across threads without locks. The entries are an immutable snapshot that writers replace with a compare-exchange, so fire() and snapshot() never block and a hook may add or remove hooks, including itself, while it runs. A fire in progress finishes over the entries it started with. Replaced snapshots are freed once no reader holds one.
