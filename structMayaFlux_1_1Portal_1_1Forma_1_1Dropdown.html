Detailed Description

A header showing the current choice that opens into a list of options.

Configure with the setters, then place() once. After place(), selected, open, header_id, header_bounds and cursor_out are populated. The list overlays whatever lies below the header and does not advance the cursor. The header reads "v" before the current choice while closed and "^" while open. Choosing a row writes its index to selected, updates the header and closes the list. Lists longer than max_visible() scroll with the mouse wheel.

selected is registered with the Bridge, so Forma::bridge().at(selected) reads the index like any other state. A Bridge inbound write changes the index but not the header caption.

auto wave = Dropdown {}
.options({ "sine", "saw", "square" })
.on_select([](size_t index) { })
.place(surface, cursor, 0.08F);
