Detailed Description

Cross-run state of the flow context.

Two atlases are bound for their whole life. Which one holds the current frame is the curr parity, passed to shaders as a push constant, so ping-pong is a bit flip and never rewrites a descriptor. Detections, retained previous points and tracks live in the flow context's shared buffers and never leave the GPU except for the final tracks readback.
