Isolate one ConnectedComponents label's silhouette on GPU, through the explicit context set that produced the label buffer.

Dispatches vision_label_select.comp through contexts.component_contours, the same context ConnectedComponents/FindContours already own: reads dense_label in place at its existing binding, no cross-context buffer copy. Requires a ConnectedComponents step to have already run against these exact contexts (this run or an earlier one); dense_label holds whichever frame's labels were computed last.

Parameters
contextsThe same context set a prior run() populated.
sourceFrame to select pixels from, eShaderReadOnlyOptimal.
target_label1-based label id, matching BoundingBox::label_id / Contour::label_id from that same run.
wFrame width in pixels.
hFrame height in pixels.
Returns
New image, transparent everywhere outside the selected label's silhouette.
