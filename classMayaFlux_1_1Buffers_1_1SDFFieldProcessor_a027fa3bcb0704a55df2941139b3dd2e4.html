Evaluate an authored field function instead of a shader file.

The shader is generated from field: its function is emitted as written and a kernel body calls it at every grid corner. Time and the parameter block reach it through set_time() and set_params(), so animating a field recompiles nothing.

Parameters
grid_bufHOST_STORAGE buffer sized to (res_x+1)*(res_y+1)*(res_z+1) floats.
fieldParsed field function, from MF_FIELD, MF_FIELD_T or MF_FIELD_P.
bounds_minWorld-space minimum corner.
bounds_maxWorld-space maximum corner.
res_xCell count along X.
res_yCell count along Y.
res_zCell count along Z.
