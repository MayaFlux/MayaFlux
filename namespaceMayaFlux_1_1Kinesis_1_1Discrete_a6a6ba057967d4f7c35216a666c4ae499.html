MAYAFLUX_API double MayaFlux::Kinesis::Discrete::pattern_lookup ( std::span< const double >  window,
std::span< const double >  coefs 
)
noexcept

Table indexed by the recent shape of the window.

coefs: [levels, count, lo, hi, table...]. The newest count values are each quantised to one of levels cells over [lo, hi] (Lattice1D), combined into an index with the newest value as the lowest digit, and the table of levels^count entries is read there. Values outside [lo, hi] fall in the edge cells and missing values count as zero. A table too small for the index range, or hi not above lo, gives zero.
