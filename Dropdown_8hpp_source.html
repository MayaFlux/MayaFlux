9/**
10 * @struct Dropdown
11 * @brief A header showing the current choice that opens into a list of options.
12 *
13 * Configure with the setters, then place() once. After place(), selected,
14 * open, header_id, header_bounds and cursor_out are populated. The list
15 * overlays whatever lies below the header and does not advance the cursor.
16 * The header reads "v" before the current choice while closed and "^" while
17 * open. Choosing a row writes its index to selected, updates the header and
18 * closes the list. Lists longer than max_visible() scroll with the mouse wheel.
19 *
20 * selected is registered with the Bridge, so Forma::bridge().at(selected)
21 * reads the index like any other state. A Bridge inbound write changes the
22 * index but not the header caption.
23 *
24 * @code
25 * auto wave = Dropdown {}
26 * .options({ "sine", "saw", "square" })
27 * .on_select([](size_t index) { })
28 * .place(surface, cursor, 0.08F);
29 * @endcode
30 */
