Position that integrates a velocity you can change while it plays.

Parameters
startPosition at time zero
velocityPosition units per second, read at every evaluation. Negative reverses and zero holds.

The position carries on from wherever it is when the velocity changes, so speeding up, slowing down, reversing or stopping never jumps. Unlike the other factories this map keeps a running position, so give each voice its own instance. Time going backwards restarts it from start.
