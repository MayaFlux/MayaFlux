9/**
10 * @class DelimitedTextReader
11 * @brief Incremental CSV and TSV reader producing CompositeArray values.
12 *
13 * A header row supplies field names by default. Without a supplied layout,
14 * every field is stored as UTF-8 text, preserving values without speculative
15 * numeric inference. Supply a CompositeLayout before open() to select exact
16 * arithmetic field types; header names must then match its field order.
17 * Empty numeric cells and missing trailing cells remain absent. An
18 * unquoted empty text cell is absent; a quoted empty cell is present.
19 * char, signed char, and unsigned char fields parse as small integers via
20 * from_chars, the same path as every other arithmetic type; a cell must
21 * contain a number such as "65", not a literal character such as "A".
22 *
23 * Usage:
24 * @code
25 * CompositeLayout layout;
26 * layout.add_field<std::string>("name");
27 * layout.add_field<double>("score");
28 * DelimitedTextReader reader;
29 *
30 * reader.set_layout(std::move(layout));
31 * if (reader.open("scores.csv")) {
32 * while (auto batch = reader.read_next(512)) {
33 * if (batch->empty())
34 * break;
35 * }
36 * }
37 * @endcode
38 *
39 * CSV and TSV share the same quoting rules. The delimiter defaults to the
40 * file extension and can be overridden before open().
41 */
