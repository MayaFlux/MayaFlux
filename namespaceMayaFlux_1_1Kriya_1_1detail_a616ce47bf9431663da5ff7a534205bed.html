bool MayaFlux::Kriya::detail::ensure_rendering ( const std::shared_ptr< Buffers::VKBuffer > &  buffer,
const Portal::Graphics::RenderConfig &  config 
)

Make a buffer draw to the window in a render config, unless it already does.

A buffer that already has a render processor is left as it is; a different target window than the one requested is reported. Otherwise the config is applied through the buffer's own setup_rendering, chosen by buffer type: the texture, geometry, mesh, network, grid and Forma families are covered. Any other buffer is reported and left untouched.

Returns
True if the buffer renders after the call.
