bool MayaFlux::IO::IOManager::save_composite ( const std::shared_ptr< Kakshya::CompositeContainer > &  container,
const std::string &  filepath 
)

Save a complete CompositeContainer in a supported format.

The write is synchronous, unlike the queued save_image, save_mesh, and save_volume. For bounded writes of large data, use open_composite_writer() and supply slices directly. A partial file may remain on failure.

Parameters
containerSource container.
filepathDestination CSV or TSV path.
Returns
True only if every element was written and the file closed.
