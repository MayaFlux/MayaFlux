Schedules a typed pattern whose steps are spaced by a list of durations.

Template Parameters
IndexStep index type, default uint64_t
Parameters
generatorCallable from the step index to any value
callbackCallable that takes the generated value
durationsSeconds to wait after each step, stepped through in order and repeated
nameName of the pattern task (optional but recommended)
tokenProcessing token to determine which scheduler rate to use (default: SAMPLE_ACCURATE)

The value type is whatever the generator returns, so no std::any is involved. schedule_pattern(gen, cb, { 0.25, 0.5 }) selects this overload.
