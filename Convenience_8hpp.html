Detailed Description

Everyday headers and namespace imports for user code.

Includes the node, buffer, task, container, geometry, window, portal and IO headers a typical project touches, then opens their namespaces so names such as Sine, AudioBuffer or SamplingPipeline need no qualification.

MayaFlux.hpp includes this file unless MAYAFLUX_NO_CONVENIENCE is defined. Define it to keep the global namespace clean and include only what you use. Simulation and compute headers are separate, see SimulationIncludes.hpp and WorkflowIncludes.hpp.

Note
The using directives apply to the including translation unit. Library headers must never include this file.
