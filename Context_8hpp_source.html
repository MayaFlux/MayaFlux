21/**
22 * @class Context
23 * @brief Event wiring between a Layer and a window surface.
24 *
25 * Subscribes to mouse events on a window by constructing Kriya input
26 * coroutines and registering them with a Vruta::EventManager, following
27 * the same pattern as Nexus::Fabric. The EventManager and Window are
28 * injected; Context holds no engine-level singletons.
29 *
30 * Callbacks fire on the scheduler tick. They must not touch GPU resources
31 * directly. State intended for the graphics tick should be written through
32 * shared_ptr captures and read on the next graphics cycle.
33 *
34 * All registered events are cancelled on destruction via
35 * EventManager::cancel_event, keyed by names scoped to this Context.
36 *
37 * Window dimensions are read from window->get_state() at event time,
38 * so resize is handled automatically.
39 */
40class MAYAFLUX_API Context {
41public:

257 /**
258 * @brief Register a key handler that fires on the initial press and on
259 * every repeat, with a deterministic first event.
260 *
261 * WindowEventSource pops events from one shared pending-event queue,
262 * and dispatch() lets every registered waiter for a key race to pop
263 * the same KEY_PRESSED. on_held's filter alone would still catch that
264 * first press if it were the only waiter on the key, but once another
265 * waiter for the same key exists on this Context, whichever registered
266 * first wins the race and the other sees nothing for that tick.
267 * Registering on_press before on_held, as this does, makes the outcome
268 * deterministic: on_press claims the initial KEY_PRESSED and on_held is
269 * then only ever resumed by the KEY_REPEAT events that follow. One fire
270 * per physical press, a clean repeat cadence after, no double count.
271 *
272 * @param id Element id to bind to.
273 * @param key The key to listen for.
274 * @param fn Callback receiving element id, fired once on press and
275 * again on each repeat tick.
276 * @return *this for chaining.
277 */
278 Context& press_and_hold(uint32_t id, IO::Keys key, KeyFn fn);
