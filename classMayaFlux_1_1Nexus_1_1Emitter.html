Detailed Description

Object that acts on existing MayaFlux objects when committed.

Constructed with an optional influence function. Position is optional: call set_position before registering with Fabric if spatial indexing is required. Entities without a position are committed normally but are not inserted into the spatial index.

The id is assigned by Fabric::wire and is stable for the object's lifetime. It is zero until the object has been registered.

RenderConfig takes a designated initializer.

emitter->set_influence<InfluenceBlock>(InfluenceBlock::from, bind_influence_block(proc));
emitter->render(mgr, { .target_window = window });
