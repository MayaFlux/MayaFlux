Build the current frame's pyramid atlas from the working image.

Submitted as one un-awaited dependency sequence, one fused dispatch per level. The level 0 stage carries a hazard on the working image, which orders any later dispatch that overwrites it after this read. The fence is reaped on the next fresh run and in reset().

Parameters
src_channelChannel of the working image read as intensity: 0 for a gray frame, 2 for the value channel of an HSV frame.
