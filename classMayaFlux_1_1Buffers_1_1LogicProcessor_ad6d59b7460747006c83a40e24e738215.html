std::shared_ptr< LogicProcessor > MayaFlux::Buffers::LogicProcessor::clone ( ) const

An independent processor over a clone of the node.

Same reset policy, modulation type, custom modulation function and remap values; the node is cloned, so its history and coefficient array are not shared. Attach one clone per channel instead of one processor to several.
