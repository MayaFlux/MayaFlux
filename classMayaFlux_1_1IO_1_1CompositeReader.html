Detailed Description

Typed FileReader boundary for schema-bearing Composite data.

Concrete readers return CompositeArray values without flattening their layout or text storage into unrelated DataVariant channels. The inherited DataVariant and SignalSourceContainer result methods are unsupported. get_layout() exposes the schema a concrete reader established on open(), so a caller can inspect field names and types before reading any data.

Usage:

std::unique_ptr<CompositeReader> reader =
std::make_unique<DelimitedTextReader>();
if (reader->open("measurements.csv")) {
auto first = reader->read_next(1024);
auto remaining = reader->read_composite();
}
Note
read_composite() reads from the current position. Call seek({0}) first to read the complete file after earlier bounded reads.
