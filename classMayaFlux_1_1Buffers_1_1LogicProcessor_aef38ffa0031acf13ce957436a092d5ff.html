void MayaFlux::Buffers::LogicProcessor::add_key ( const std::shared_ptr< AudioBuffer > &  buffer)

Reads another buffer as an extra input slot of a parallel node.

Parameters
bufferThe key, for example another channel or a sidechain

With a parallel Logic node, every sample is evaluated with one slot per key, in the order added, followed by this buffer's own sample, the same order input nodes use. The key is read as it stands when this buffer is processed, so process it first; a key shorter than this buffer or no longer alive reads as silence. Keys are ignored by a node that is not parallel.
