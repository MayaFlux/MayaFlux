Detailed Description

Defines one slot's block as a function of other slots' blocks.

For each frame, calls the function with the input slots' values in the order given and writes the result to the target slot's block. An input equal to the target reads that slot's previous frame, or its previous block's last value at frame 0. Place after AdvanceOperator.

Three forms of rule:

  • a plain function of the input values;
  • a function of the input values and a coefficient array, which keeps the rule's state and can be retuned, saved and shared between rules;
  • a boolean function of the input values and a coefficient array, such as the parallel kernels of Kinesis::Discrete (Boolean.hpp). The block holds 0 or 1, and the target's activity follows the result, so its on_enter and on_leave callbacks fire on each change.

Coefficients are parameters "c0", "c1", ...: map("c2", source) retunes coefficient 2 at the start of every block.

namespace D = Kinesis::Discrete;
n->add<DeriveOperator>(2, std::vector<size_t> { 0, 1 }, D::comparator, D::comparator_state(0.2));
n->get_slot(2).on_enter.push_back([bell] { bell->excite(0.6); });
