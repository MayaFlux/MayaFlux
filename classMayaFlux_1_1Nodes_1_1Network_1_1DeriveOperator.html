Detailed Description

Defines one slot's block as a function of other slots' blocks.

For each frame, calls the function with the input slots' values in the order given and writes the result to the target slot's block. An input equal to the target reads that slot's previous frame, or its previous block's last value at frame 0. Place after AdvanceOperator.
