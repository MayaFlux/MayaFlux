Detailed Description

Named multichannel extraction functions for FeatureExtractor.

One function per ExtractionMethod case. Each operates on a vector of const double spans (one per channel) and returns one output vector per channel. Single-channel callers use channels[0].

No classes, no analyzer dependencies, no indirection. All math delegates directly to Kinesis::Discrete.
