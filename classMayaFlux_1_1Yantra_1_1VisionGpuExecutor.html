Detailed Description

Stateful GPU dispatch engine for VisionSequence execution.

Owns a lazily-constructed VisionGpuContexts (m_contexts) plus any op-specific persistent GPU state that doesn't belong on a shared context (e.g. ConnectedComponents' ping-pong output image). Mirrors VisionExecutor's ownership model on the CPU side: construct one instance per independent pipeline, hold it, call run() every frame.

Immovable: TextureExecutionContext owns GPU resource handles with no copy or move constructor, so VisionGpuContexts and therefore VisionGpuExecutor cannot be copied or moved either. Construct once, hold by reference, pointer, or shared_ptr, reuse indefinitely.

Not safe to call run() concurrently from multiple threads on the same instance. Independent pipelines running concurrently should each own a separate VisionGpuExecutor instance.
