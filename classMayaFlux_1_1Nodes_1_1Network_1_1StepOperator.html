Detailed Description

General operator whose body is a callable, run once per block.

Mapped parameters are stored by name and readable from the body through parameter().

net->add<StepOperator>([](StepOperator& self, std::span<RelationSlot> slots, uint32_t frames) {
for (auto& slot : slots) {
if (slot.level > self.parameter("limit")) {
slot.set_active(false);
}
}
});
