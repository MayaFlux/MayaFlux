Detailed Description

Read view of one value in a CompositeArray.

Borrows a layout and two DataVariant stores. Arithmetic access copies one value from packed bytes, so the field need not be naturally aligned. Numeric getters require an exact declared type. Missing and mismatched fields return std::nullopt.

Usage:

auto item = items.at(0);
auto name = item->text("name");
auto score = item->get<double>("score");
bool has_age = item->has("age");
