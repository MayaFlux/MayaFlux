Detailed Description

Combines each sample with lagged values of its own carried stream.

Per sample the processor reads one value per tap from a ring of carried values, calls the combiner with the current sample, those tap values and the coefficient array, writes the result to the buffer and pushes the carried value into the ring. Lags start at one sample, so recursion within a block is possible. State (ring, coefficient array, lag ramps) is kept per attached buffer, so one processor can serve many buffers and clones never share history.

Works on any AudioBuffer. On a FeedbackBuffer the ring is the buffer's own.
