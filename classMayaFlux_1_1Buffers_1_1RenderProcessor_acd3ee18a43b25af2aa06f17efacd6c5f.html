void MayaFlux::Buffers::RenderProcessor::execute_shader ( const std::shared_ptr< VKBuffer > &  buffer)
overrideprotectedvirtual

Prepare this buffer's geometry and record its draw commands.

Publishes the view transform and advances triangulation before recording. Valid empty geometry still records a secondary command buffer so normal processing can present an empty frame. Presentation refreshes call record_draw() directly to reuse the prepared geometry.

Implements MayaFlux::Buffers::ShaderProcessor.
