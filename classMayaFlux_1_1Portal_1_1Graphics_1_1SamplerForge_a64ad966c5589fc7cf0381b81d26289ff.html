Work out how a source extent maps onto a destination extent.

Pure arithmetic, no device needed. Zero in any extent yields an empty plan. Tiling produces one blit per tile, so a source much smaller than the destination produces many.

Parameters
src_widthSource width in pixels.
src_heightSource height in pixels.
dst_widthDestination width in pixels.
dst_heightDestination height in pixels.
modeHow the source is fitted.
filterFilter for the blits and the sampler.
Returns
Rectangles for an image write and the matching sampler.
