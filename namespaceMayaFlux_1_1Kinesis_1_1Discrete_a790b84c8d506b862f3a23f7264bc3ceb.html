MAYAFLUX_API double MayaFlux::Kinesis::Discrete::quantile ( std::span< const double >  window,
std::span< const double >  coefs 
)

Quantile of the whole window, interpolating between ranks.

The per-call counterpart of Discrete::percentile, which is the batch form over every window of a buffer and takes percent.

coefs[0] is the quantile in [0, 1], 0.5 when the array is empty: 0 is the minimum, 1 the maximum. Uses a per-thread scratch vector, so it allocates only the first time a window of a new size is seen.
