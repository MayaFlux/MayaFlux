void MayaFlux::Buffers::RelaxationStepProcessor::processing_function ( const std::shared_ptr< Buffer > &  buffer)
overrideprotectedvirtual

Run one cycle: evaluate the predicate, write the state descriptors, run the parent, then swap and serve a snapshot if a dispatch was recorded.

The descriptor write must precede the parent's bind_descriptor_sets. A write from on_before_execute lands on a set already bound into the open command buffer, which the driver has consumed by then, freezing the bindings at whatever on_descriptors_created wrote.
