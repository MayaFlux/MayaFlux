inlinenoexcept

Write a level into an evenly spaced sample array at a fractional position, filling linearly from the previously written index.

position in [0, 1] selects the index (0 is the first sample, 1 the last). level is clamped to [0, 1]. When previous holds a different valid index, every sample between that index and the new one is set on the line from the value last stored at previous to level, in either direction, so a fast gesture leaves no gaps. previous is updated to the index just written; reset it to clear the gesture.

A NaN position selects the first sample; infinite positions clamp to the nearest end. An empty array is untouched.

Parameters
samplesSamples to write into.
previousIndex written by the previous call of this gesture.
positionFractional position in [0, 1].
levelLevel in [0, 1].
