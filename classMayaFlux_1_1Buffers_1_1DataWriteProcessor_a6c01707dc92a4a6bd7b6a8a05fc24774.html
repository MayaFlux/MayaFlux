void MayaFlux::Buffers::DataWriteProcessor::write_texture_pixels ( Kakshya::ImageData  image)

Write pixels straight into the attached TextureBuffer's GPU image.

The image must match the GPU image's format and size, which must be writable (transfer-destination usage). Retained host pixels that are marked dirty re-upload over this write.
