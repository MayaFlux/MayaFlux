13 * @brief Factory free functions for the Forma surface system.
14 *
15 * Call initialize() once after engine startup to store BufferManager,
16 * TaskScheduler, and EventManager references. Subsequent factory calls
17 * require only the arguments that legitimately vary per call (Window,
18 * geometry function, initial value). This matches the Portal::Text and
19 * Portal::Graphics initialization contracts.
20 *
21 * Typical sequence:
22 * @code
23 * Portal::Forma::initialize(buffer_manager, scheduler, event_manager);
24 *
25 * auto [layer, ctx] = Forma::create_layer(window, "hud");
26 *
27 * auto el = Forma::create_element<float>(
28 * *layer, window, geom_fn, 0.5f);
29 *
30 * auto bridge = Forma::create_bridge();
31 * bridge.bind(el.state, envelope);
32 * bridge.write(el.state, compute_proc, offsetof(PC, cutoff));
33 *
34 * ctx->on_press(el.element.id, IO::MouseButtons::LEFT,
35 * [](uint32_t, glm::vec2){});
36 * @endcode

220/**
221 * @brief Tear down an element and everything related to it.
222 *
223 * The symmetric counterpart to create_element/create<T>/create_text_field:
224 * walks surface.layer().closure(id) (id plus every id transitively
225 * related via Layer::relate, e.g. a Collapsible's attached body, a
226 * Scrollable's tracked rows, or a TextField's Scrollable viewport), calls
227 * Context::unbind and Bridge::unbind on each id in that closure, then
228 * Layer::remove(id) - which itself cascades the Layer-side removal
229 * (buffer mark_for_removal, m_elements erase, m_relations cleanup) across
230 * the same closure.
231 *
232 * This is the one call callers should use to tear down a composed Forma
233 * element. Layer::remove(id) alone is still available for callers that
234 * only need the Layer-side cascade with no Context/Bridge involvement.
235 *
236 * @param surface Surface owning the Layer, Context, and (via the module
237 * Bridge) the bindings @p id may participate in.
238 * @param id Element id to remove, as returned by layer().add()/Slot::id().
239 */
