◆ read_camera()

std::shared_ptr< Buffers::VideoContainerBuffer > MayaFlux::Creator::read_camera ( const IO::CameraConfig &  config)

Open a camera device and register it as a pipeable live source.

Opens via IOManager::open_camera(), hooks the resulting CameraContainer to a VideoContainerBuffer via IOManager::hook_camera_to_buffer(), and returns the buffer — already pipeable through the generic VKBuffer path (register_buffer), the same way read_image() returns an already-pipeable TextureBuffer instead of a raw container.

There is no dialog-backed no-argument overload: a camera is a device to configure, not a file to browse to, the same reasoning behind read_hid/read_midi/read_osc/read_tablet taking a config directly.

Parameters
configDevice name, resolution hint, fps hint, format override.
Returns
Hooked VideoContainerBuffer, or nullptr on failure.
