Detailed Description

Owning homogeneous NDData projection of one Composite field.

Presence contains one uint8_t per element: 1 for present, 0 for absent. Values for absent elements are zero-filled and must be interpreted using the presence variant. The dimension describes the projected field as a one-dimensional TENSOR_ND value sequence.

Usage:

auto projection = items.to_nddata<double>("score");
const auto& scores = std::get<std::vector<double>>(projection->values);
const auto& present = std::get<std::vector<uint8_t>>(projection->presence);
