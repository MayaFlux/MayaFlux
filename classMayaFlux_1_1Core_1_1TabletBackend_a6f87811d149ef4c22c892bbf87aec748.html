TabletLayout MayaFlux::Core::TabletBackend::parse_descriptor ( std::span< const uint8_t >  descriptor)
static

Parse a HID report descriptor into a tablet layout.

Free of device state and of HIDAPI, so captured descriptor bytes can be parsed and asserted against with no hardware present.

Parameters
descriptorRaw report descriptor bytes.
Returns
Parsed layout. No fields means no digitizer usages were found.
