Detailed Description

Validated, non-owning access to packed Composite NDData storage.

The element and text stores remain DataVariant instances holding vector<uint8_t>. The layout interprets field offsets within each packed element. No byte or field conversion occurs when creating this view.

Usage:

auto access = items.access();
auto first = access->at(0);
auto bytes = access->element_bytes();
auto dimensions = access->byte_dimensions();

Access to externally owned packed variants:

auto access = as_composite_access(elements, text, layout);
