Detailed Description

Headers for field, grid, volume and spatial cache simulations.

Include after MayaFlux.hpp. Every group is included unless you leave it out by defining its macro before this include:

  • MAYAFLUX_SIMULATION_NO_FIELDS: GPU field operators, vertex and UV field processors, spatial hash, claim and population processors, force fields, and the spatial cache, transfer, reader and export
  • MAYAFLUX_SIMULATION_NO_GRID: relaxation grid buffers and processors
  • MAYAFLUX_SIMULATION_NO_VOLUME: volume buffers, fluid processors, raymarching and volume file IO

Code that builds directly on the underlying types can include only the headers it uses instead.
