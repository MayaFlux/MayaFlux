bool MayaFlux::IO::IOManager::save_spatial_snapshot ( std::vector< IO::SpatialCaptureSource >  sources,
const std::string &  path_pattern 
)

Save every source once, as a single time sample, with a millisecond epoch timestamp spliced into the path, queued asynchronously.

The timestamp is computed on the worker thread at the moment the write actually runs, mirroring save_mesh_snapshot, so repeated calls in quick succession still each land in their own file.

Returns
True once the task is queued; open or write failure is logged from the task and does not surface here.
