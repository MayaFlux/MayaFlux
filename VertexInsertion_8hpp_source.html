7/**
8 * @class VertexInsertion
9 * @brief Write counterpart to VertexAccess: splits interleaved vertex bytes into typed channels.
10 *
11 * Parallel to MeshInsertion and DataInsertion: holds a mutable reference to a
12 * channel list and populates it. Each VertexLayout attribute becomes one
13 * DataVariant, in layout order, holding the attribute for every vertex:
14 *
15 * VERTEX_POSITIONS_3D, NORMALS_3D, TANGENTS_3D, COLORS_RGB -> vector<glm::vec3>
16 * TEXTURE_COORDS_2D -> vector<glm::vec2>
17 * VERTEX_COLORS_RGBA -> vector<glm::vec4>
18 * SCALAR_F32 -> vector<float>
19 *
20 * For the canonical point, line and mesh layouts the channel order matches the
21 * slot order as_point_vertex_access() and its siblings consume, so a read
22 * channel list can be written back without reordering.
23 *
24 * Nothing is written unless the layout and byte count are both valid.
25 *
26 * Usage:
27 * @code
28 * std::vector<DataVariant> channels;
29 * VertexInsertion ins(channels);
30 * if (ins.insert_interleaved(bytes, layout)) {
31 * auto& positions = std::get<std::vector<glm::vec3>>(channels[0]);
32 * }
33 * @endcode
34 */
