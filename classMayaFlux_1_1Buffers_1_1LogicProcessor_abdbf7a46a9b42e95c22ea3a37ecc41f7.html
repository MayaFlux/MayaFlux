void MayaFlux::Buffers::LogicProcessor::set_bit_planes ( uint32_t  bits)

Processes every sample as a word of bit streams, one node per bit.

Parameters
bitsWord width, 1 to 24; 0 turns it off

Each sample becomes an offset binary word (Kinesis::Discrete::to_word) and every bit position runs through its own clone of the node, so each plane keeps its own state. Planes are presented to the node as 0.0 or 1.0 and the output bits are recombined into the sample, so the logic data is a value in [-1, 1] rather than a bit. With a parallel node and keys, plane j sees plane j of every key and of this buffer: bitwise word operations across channels. The clones are taken at the next block and again when the node is replaced or this is called.
