104/**

106 * one's parameters.
107 *

142/**
143 * @brief Resolve a VisionQuery into the ResolvedSequences needed to
144 * satisfy every active intent.
145 *
146 * TrackObjects and EstimateMotion, when both active, resolve into one
147 * sequence sharing a tail; neither can be split back apart afterward.
148 * Every other active intent gets its own sequence, seeded from whichever
149 * leading steps it has in common with the first sequence (matched by
150 * VisionOp and params) instead of recomputing them. Sharing happens only
151 * when neither sequence runs a step that overwrites the executor's shared
152 * output images after the shared prefix, because such a step would already
153 * have destroyed the seed. Seeded sequences are returned right after the
154 * first, unseeded ones last, and DetectEdges last of all so the edge image
155 * it hands back is not overwritten by a later sequence.
156 *
157 * @param query Active intents and their parameters.
158 * @return Ordered ResolvedSequences to run against the same frame; empty
159 * when no intent in query.intents has a populated parameter
160 * field.
161 */
162[[nodiscard]] MAYAFLUX_API std::vector<ResolvedSequence> resolve(const VisionQuery& query);
