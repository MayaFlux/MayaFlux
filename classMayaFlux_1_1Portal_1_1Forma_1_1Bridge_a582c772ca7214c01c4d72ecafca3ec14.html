Register a MappedState<T> so that MappedState overloads and outbound bindings can resolve to the correct element and reader.

Called by Forma::create_element. The reader closes over the MappedState and is stored type-erased as std::function<float()>. The state records ref so later calls made through it address the same element. Rejected, with an error logged, when the Layer in ref has no shared_ptr owner.

Template Parameters
TMappedState value type.
Parameters
refOwning Layer and the element id from Layer::add.
stateMappedState to register.
bufferFormaBuffer the element renders into.
projectOptional T -> float projection. Identity cast if empty.
