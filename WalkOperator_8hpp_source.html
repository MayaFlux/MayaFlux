7/**
8 * @class WalkOperator
9 * @brief Moves a single active slot along the rows of a weight table
10 *
11 * Exactly one slot is meant to be active at a time. advance() reads the row
12 * of the current slot, picks a successor, deactivates the current slot, and
13 * activates the successor, so the slots' leave and enter callbacks fire in
14 * that order. jump() moves directly. Nothing else changes the state.
15 *
16 * WalkOperator can be stepped two ways, and both may be used on the same instance:
17 *
18 * 1. External: call advance() from a node hook, a Vruta or Kriya task, another
19 * operator, or user code. This is sample- or event-accurate, but requires
20 * something outside the network to call it.
21 *
22 * 2. Self-contained: construct with every_n_blocks > 0. process(), which the
23 * network's operator chain already calls once per process_batch() with no
24 * external wiring, then calls advance() itself every N blocks. This is
25 * coarser (block-resolution, not sample-accurate) but requires nothing
26 * outside the network to make the chain progress at all. every_n_blocks is
27 * 0 by default, meaning process() does nothing and only external calls to
28 * advance() move the walk.
29 *
30 * The table is a shared pointer so other operators and writers can read or
31 * edit the same weights, and any cell may be rewritten while the walk runs.
32 * The draw itself uses an owned Kinesis::Stochastic::Stochastic generator
33 * (UNIFORM by default).
34 *
35 * The first call to process(), advance(), or jump() establishes the single-
36 * active-slot state: it activates starting_index (0 unless the constructor
37 * was given a different one) and deactivates every other slot that exists
38 * at that moment, before doing anything else. A slot added by add_slot()
39 * afterward starts at RelationSlot's own default (active) like any other
40 * new slot; WalkOperator does not retroactively enforce its invariant on
41 * it. jump() it explicitly to bring it into the walk.
42 *
43 * Parameters:
44 * - "current": jumps to that slot index when it differs from the current one,
45 * so a mapped Source can steer the walk.
46 *
47 * The table must be square with a dimension equal to the slot count of the
48 * network. advance() and jump() mutate the walk and must not be called
49 * concurrently from more than one thread. Reads are atomic.
50 */
