MAYAFLUX_API bool MayaFlux::Buffers::clear_gpu_buffer ( const std::shared_ptr< VKBuffer > &  target)

Zero a registered GPU buffer in place (auto-detects host-visible vs device-local)

Parameters
targetBuffer to clear
Returns
True if the buffer was cleared

Mapped buffers are cleared on the host. Unmapped buffers are filled on the GPU with no staging allocation, and the call blocks until the fill is done. Handles and device addresses are unchanged. Logs an error and returns false if the buffer is null or unregistered, lacks transfer destination usage, or the BufferService is unavailable. Never throws.
