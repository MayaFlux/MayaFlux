7/**
8 * @class BlockFeedbackProcessor
9 * @brief Compares and transforms each whole block against an earlier block
10 *
11 * Where FeedbackProcessor works sample by sample, this works on the block as
12 * a unit: every cycle it hands a function the current block, the block from a
13 * set number of cycles ago and a coefficient array, and keeps what the
14 * function leaves in the buffer for later cycles. The function may rewrite
15 * the current block in place and returns one number, a feature of the block
16 * (a distance, a correlation, a level against the earlier one), which is
17 * stored per buffer and passed to an optional observer.
18 *
19 * State (retained blocks, coefficient array, last feature) is kept per
20 * attached buffer. Works on any AudioBuffer. Until enough cycles have passed
21 * the earlier block is zeros.
22 */
