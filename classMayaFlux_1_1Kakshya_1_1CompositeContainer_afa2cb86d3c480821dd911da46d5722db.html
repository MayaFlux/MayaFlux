bool MayaFlux::Kakshya::CompositeContainer::materialize_next ( )

Copy the next bounded window into independent storage.

Returns
True if a nonempty window was copied; false at the end or if an element could not be copied. On failure, the prior window and current position are preserved.
Note
Selected text is copied into the window's own text store.
