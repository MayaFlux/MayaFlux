void MayaFlux::Buffers::DataWriteProcessor::write_buffer ( std::shared_ptr< VKBuffer >  target,
Kakshya::DataVariant  data,
size_t  dst_offset = 0 
)

Write bytes into another VKBuffer, such as a plain descriptor-bound buffer.

The target is not resized. A device-local target is written through a persistent staging buffer. A buffer whose descriptor binding has a node, audio, or host-buffer source is rewritten from that source each cycle, so write to the source instead.

Parameters
targetBuffer to write; retained until the request runs.
dataSource data, converted to bytes when the request runs.
dst_offsetByte offset into target. offset plus data size must fit its allocation.
