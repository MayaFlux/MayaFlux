77/**
78 * @class FeedbackProcessor
79 * @brief Combines each sample with lagged values of its own carried stream
80 *
81 * Per sample the processor reads one value per tap from a ring of carried
82 * values, calls the combiner with the current sample, those tap values and
83 * the coefficient array, writes the result to the buffer and pushes the
84 * carried value into the ring. Lags start at one sample, so recursion
85 * within a block is possible. State (ring, coefficient array, lag ramps) is
86 * kept per attached buffer, so one processor can serve many buffers and
87 * clones never share history.
88 *
89 * Works on any AudioBuffer. On a FeedbackBuffer the ring is the buffer's own.
