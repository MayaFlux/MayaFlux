Detailed Description

Runs vision queries over video streams, image lists and texture containers, delivering what an extraction takes from each frame.

The live methods set a run going on the engine: an analysis producer on the scheduler and a delivering consumer on the event manager. They need a constructed workflow, and accept any video stream: a camera, a video file or a dynamic stream. A run keeps going until its stream reaches its end, stop_all(), the workflow's destruction, or engine shutdown. The managers are held weakly, so a workflow kept past shutdown keeps nothing alive and stops nothing.

The finite methods are static: they run to completion on the calling thread and need no engine, so call them where no other vision work is running.

In every method an intent set in the query without its parameters runs with the defaults, and tracking and motion carry from one frame to the next. The extraction mode must produce an image.
