Drive a network's vertices with fields and spatial stages, and attach rendering.

Template Parameters
NetworkA field-compatible NodeNetwork subclass, such as ParticleNetwork.
Parameters
networkUnregistered network.
spatialSpatial hash, claim, density and population configuration. Default constructed means field displacement only.
bindCalled with the GpuFieldOperator before the geometry buffer is registered. May be empty when the config alone is wanted.
renderRender target. target_window is required.
Returns
The network, or nullptr if it is null, has no primary GraphicsOperator to read a layout from, or the target window is null.

A ParticleNetwork with no primary operator and its default operator enabled receives a PhysicsOperator. The GpuFieldOperator is created with the primary operator's vertex layout and appended to the network's operator chain, or reused if the chain already holds one, in which case spatial is ignored. The network and its NetworkGeometryBuffer are then registered in the graphics domain and rendering is attached. Registering the buffer wires the field pass and every spatial stage the config selects.
