Download and save a GPU-resident volume to disk asynchronously.

Mirrors save_image(VKImage): download, writer lookup and write all happen inside the dispatched task, so this returns as soon as the task is queued rather than blocking the caller. The future is tracked in the same pool as every other save task; wait_for_pending_saves() waits on it like any other.

Parameters
volumeVolume to read from.
filepathDestination path; extension selects the writer.
optionsWriter options.
field_namesFields to save. Empty means every declared field.
Returns
True once the task is queued. Download or write failure is logged from the task and does not surface here.
