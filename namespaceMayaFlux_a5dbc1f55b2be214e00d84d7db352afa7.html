MAYAFLUX_API bool MayaFlux::save_spatial ( std::vector< IO::SpatialCaptureSource >  sources,
const std::string &  suggested_name = "output.abc" 
)

Present a native save-file dialog filtered to Alembic and write every source once via IOManager::save_spatial_snapshot().

Blocks until the user confirms or cancels. The write itself is queued asynchronously; this function returns once the path is chosen and the task is enqueued. Returns false on cancellation, backend error, or if Portal::System is not initialized.

Parameters
sourcesStreams to write once. Build with IO::make_network_geometry_source() or a hand-written IO::SpatialCaptureSource.
suggested_nameFilename pre-filled in the dialog name field.
