uint64_t MayaFlux::Kakshya::DynamicSoundStream::append_frames ( std::span< const double >  data,
uint32_t  channel = 0 
)

Write one channel at its write head and advance the head.

Linear mode appends after the last frame written, growing the stream if auto-resize is on. Circular mode wraps at capacity and overwrites the oldest frames; a block larger than the capacity keeps only its newest frames. Each channel has its own head, so writing every channel of a stream once per cycle keeps them aligned.

Parameters
dataSamples for one channel.
channelChannel to write.
