Detailed Description

Declarative "what to do" vocabulary, one layer above VisionOp.

VisionOp/VisionStep/VisionSequence (VisionOp.hpp) are the mechanism layer: a named algorithm and its parameters. VisionIntent is the layer above it: what the caller wants, independent of which VisionOps achieve it. A caller may want more than one thing from the same frame at once (track an object while also finding other elements), so this is a composable flag enum, not a single-value one.

This file is a pure value type with no MayaFlux dependency beyond the project-wide MF_BITMASK_OPERATORS macro (cmake/pch.h, force-included), matching VisionOp.hpp's own design so any consumer of a VisionSequence can eventually consume a resolved VisionIntent without knowing which specific VisionOps were chosen.
