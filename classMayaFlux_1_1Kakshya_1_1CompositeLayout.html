Detailed Description

Shared field description and byte layout for a CompositeArray.

Declare fields before constructing an array. Construction finalizes the layout, placing a presence bitmap before the fields in each element. Field order determines byte offsets. A field may be an arithmetic type or std::string; text uses the array's separate UTF-8 byte storage.

Usage:

CompositeLayout layout;
layout.add_field<std::string>("name");
layout.add_field<uint32_t>("age");
layout.add_field<double>("score");
CompositeArray items(std::move(layout));
