Non-blocking pass over every currently held item.

Atomically takes the entire chain, then for each item calls ready(item). If it returns true, calls finish(item) and frees the link. If false, the item is republished so a later sweep() or drain() will see it again.

Items pushed by other threads while this sweep is running are not part of the taken chain and are left untouched; they surface on a later sweep().

Template Parameters
PredCallable (T&) -> bool. True means the item is done and safe to finalize now.
FinishCallable (T&) -> void. Invoked exactly once per item for which ready returned true, before the link is freed.
