Compute the Harris response of the current image.

Packs and smooths image gradients before evaluating the response. The response image becomes the working image for a following ExtractPeaks.

Returns
The response image and the original input image.

Zero PeakBuf (binding 2) before pass 0 so its atomicMax starts clean; clear the staged bytes before pass 1 so the accumulated max survives.
