Template Parameters

Parameters

nameName of the pattern task (optional but recommended)
tokenProcessing token to determine which scheduler rate to use (default: SAMPLE_ACCURATE)

Forwards to Kriya::pattern, which describes both forms. A condition runs a step each time it holds; a durations function is asked once per pass and ends the pattern on an empty array.
