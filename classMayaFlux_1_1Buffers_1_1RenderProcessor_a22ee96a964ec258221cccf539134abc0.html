const Kinesis::RenderTransform & MayaFlux::Buffers::RenderProcessor::publish_render_transform ( )
protected

Resolve the view and geometry transforms and write them to the UBO.

Returns
The render transform just published.

Host-side only, no command recording. Runs before the triangulation dispatch so that reads this frame's camera. Prefer pushing the returned value into a dispatch over binding the UBO, which has no per-frame-in-flight copies.
