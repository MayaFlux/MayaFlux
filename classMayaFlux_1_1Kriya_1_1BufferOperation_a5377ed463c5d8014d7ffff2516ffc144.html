Capture a camera straight into a dynamic video stream it creates.

One operation opens the camera, hooks it to a buffer, makes a ring sized from that buffer's real frame size and format, and each cycle appends the camera frame to it. The stream is reached through get_graphics_stream() so playback can be set up, for example lag_behind_head.

Parameters
ring_framesFrames the ring keeps; zero keeps three seconds at the registered frame rate.
liveDraws the live camera when given.
displayDraws the stream through the pipeline's IOManager when given; the pipeline needs one.
