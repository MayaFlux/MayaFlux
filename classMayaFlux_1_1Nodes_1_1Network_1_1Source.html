Detailed Description

Anything that can supply a number when evaluated.

The right-hand side of a mapping wherever an operator parameter should be drivable by whatever is at hand:

  • A constant returns itself.
  • A node returns its get_last_output().
  • A NodeNetwork plus an index returns that network's get_node_output(index), or 0.0 if it has nothing there. Works the same whether the network is this RelationNetwork or any other NodeNetwork.
  • A callable is invoked on whichever thread evaluates the source, so it follows the same rules as a node hook on the audio thread.
