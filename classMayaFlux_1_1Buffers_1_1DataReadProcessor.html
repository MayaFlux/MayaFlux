Detailed Description

Reads selected buffer storage into owned host data, one snapshot per request.

Each read_* call arms one request that runs on the next graphics cycle; the matching resolve_* call finishes it on the consuming thread, waiting for a device-local copy when one is in flight. Arm again after resolving to read every frame.

Geometry: read_vertices, read_mesh. Pixels: read_host_pixels, read_texture_pixels. Data: read_bytes, read_buffer, read_field, read_back_buffer.
