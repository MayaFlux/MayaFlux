bool MayaFlux::Buffers::TextureArrayBuffer::submit_layer ( uint32_t  layer,
const std::shared_ptr< Core::VKImage > &  image 
)

Replace the frame of one layer with a GPU image, with no host read.

The image is blitted into the layer, converting format and fitting its extent as set_fit says. It must not be this buffer's own image.

Returns
True if the frame was stored.
