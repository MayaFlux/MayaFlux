void MayaFlux::Nodes::Filters::Filter::setACoefficients ( const std::vector< double > &  new_coefs)

Updates the feedback (denominator) coefficients.

Parameters
new_coefsNew coefficient values

Sets the 'a' coefficients in the difference equation, which are applied to previous output samples. The vector is normalized on entry so that a[0] is 1.0; getACoefficients() therefore returns the normalized form, not the values as supplied. Rejects vectors whose leading coefficient magnitude falls below k_min_leading_coef.
