Detailed Description

template<typename T, size_t Capacity>
class MayaFlux::Memory::PendingQueue< T, Capacity >

Bounded multi-producer, single-consumer queue of deferred operations.

Producers on any thread push an operation; the one owner of the guarded container drains the queue at a point where mutation is safe and applies each operation in the order it was claimed. Each cell carries its own sequence number, so a producer only claims a cell that is free and a consumer only reads a cell whose payload has been published. A full queue rejects the push without disturbing any other claim.

Capacity must be a power of two. T must be default constructible and move assignable; the drained cell is reset so the queue never retains a payload (for example a shared_ptr) past its application.

Only one thread may call drain() at a time.

PendingQueue<Op, 1024> queue;
if (!queue.push(Op { node, true })) {
// full: retry after the next drain
}
queue.drain([&](Op&& op) { apply(std::move(op)); });
