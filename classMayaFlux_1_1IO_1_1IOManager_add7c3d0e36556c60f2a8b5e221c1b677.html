Save an already-downloaded VolumeData to disk asynchronously.

Purely CPU-bound from here, so no thread restrictions on the caller. Encode and disk flush are dispatched to a worker; failures are logged but do not block.

The extension of filepath selects the writer via VolumeWriterRegistry. For synchronous semantics use the IO::save_volume free function in VolumeTransfer.hpp, and for a numbered frame sequence use IO::VolumeCapture.

Returns
True if the encode task was queued.
