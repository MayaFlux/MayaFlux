15 * @brief An Expanse whose region is the bounds of a buffer that already exists.
16 *
17 * The buffer's geometry is read once, when the Hull is built and on refit(),
18 * and the box is kept in the buffer's stored coordinates. Containment takes a
19 * world position back through the transform the buffer is drawn with, so the
20 * region follows the buffer wherever it is placed, for example by an Agent
21 * attached to it, and stays an exact box under rotation and scale. The buffer
22 * is neither registered nor written to, and nothing is encoded for a Hull.
23 *
24 * Only the buffer's primary render processor is read. A buffer whose geometry
25 * cannot be read contains nothing. Reading a buffer that a GpuFieldOperator drives
26 * downloads it from the device, so refit() belongs on a FRAME_ACCURATE metro.
27 */
