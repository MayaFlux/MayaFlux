void MayaFlux::Nodes::Node::exclude_output_from_graph ( bool  excluded = true)
virtual

Exclude this node's output from the graph it is registered in.

Parameters
excludedTrue to process the node without adding its output to the graph, false to restore.

The node is processed every cycle as usual: its state advances, its hooks fire and get_last_output() stays valid for anything that reads it. Only its contribution to the sum of the root it is registered on is left out. Calls to process_sample() or process_batch() are not affected.
