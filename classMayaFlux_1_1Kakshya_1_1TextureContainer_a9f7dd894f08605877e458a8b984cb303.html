Upload one layer into an existing VKImage instead of creating one.

Use this for an image retained separately from the container, such as an execution context's input image.

Parameters
imageTarget image. Must match this container's width, height and format, and be a single layer 2D image.
layerArray layer index (default 0).
stagingHost-visible staging VKBuffer sized to at least byte_size().
Returns
True when the layer was uploaded, false when the layer is out of range, empty, or the image is null.
