Detailed Description

A saturation and value square, a hue strip and a swatch, drawn into one buffer.

Configure with the setters, then place() once. After place(), picker_id, color, hsv, picker_bounds and cursor_out are populated. Pressing or dragging the square sets saturation and value, and the strip sets hue. Hue is kept in hsv, so it survives picking a grey or black. color holds the same value as red, green and blue, each in [0, 1].

color is registered with the Bridge, so Forma::bridge().at(color).write(sink) receives three floats; hsv is registered the same way and receives hue, saturation and value. A Bridge inbound write changes the value but does not move the markers. Forma::destroy(surface, picker_id) removes the picker.

auto picker = ColorPicker {}
.initial({ 0.9F, 0.4F, 0.1F })
.on_change([](glm::vec3 rgb) { })
.place(surface, cursor, 0.4F);
