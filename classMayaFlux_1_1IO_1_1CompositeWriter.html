Detailed Description

Typed writer contract for schema-bearing Composite files.

A concrete writer chooses a file format and encodes Composite fields without exposing unrestricted byte writes. A file is opened with one layout, then receives one or more bounded slices before close().

Usage:

bool save_measurements(
CompositeWriter& writer, const Kakshya::CompositeArray& array)
{
return writer.write("measurements.csv", array);
}
