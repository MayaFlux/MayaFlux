std::shared_ptr< Core::VKImage > MayaFlux::Yantra::TextureExecutionContext::container_image ( const Kakshya::TextureContainer &  container,
uint32_t  layer 
)
inlineprivate

The container's pixels as a GPU image, without allocating one per call.

The context retains its own image. TextureLoom creates one when its allocation properties change, then the container uploads current pixels into it on every call.

The image is reused in place, so the previous dispatch on this context must have completed before the next call, as it must for the output image.

Returns
The input image, or nullptr when the container has no usable data.
