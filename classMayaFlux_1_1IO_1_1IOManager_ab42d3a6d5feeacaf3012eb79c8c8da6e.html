void MayaFlux::IO::IOManager::shutdown ( )

Unregisters IOService and releases readers, writers, buffers and caches.

Calls stop() first. Call after the consuming threads have been joined and before the graphics backend is cleaned up, so objects whose destructors touch the backend are released while it is still alive. Idempotent.
