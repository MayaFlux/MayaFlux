std::span< const std::pair< uint32_t, glm::vec3 > >  snapshot

Evaluate a spatial snapshot from one Fabric against this Expanse.

Tests each position in snapshot with contains(), diffs the result against the previous occupant set for fabric_id, fires the entry and exit actions for the difference and the inside actions for everything inside, and updates the stored set. Each Fabric maintains independent occupant state.

Parameters
fabric_idStable id of the calling Fabric.
snapshotEntity id and position of every positioned entity in that Fabric.
