9/**
10 * @class DelimitedTextWriter
11 * @brief Streaming CSV and TSV writer for Composite arrays.
12 *
13 * The output delimiter defaults to the file extension. A header is
14 * written by default, and every record ends with LF. Missing fields
15 * become unquoted empty cells; present empty text becomes a quoted empty
16 * cell so DelimitedTextReader can restore its presence bit. Numbers use
17 * the shortest decimal form that parses back to the same value, and text
18 * is quoted when CSV/TSV syntax requires it. A non-finite floating-point
19 * value has no CSV form and fails the write.
20 *
21 * Usage:
22 * @code
23 * DelimitedTextWriter writer;
24 * bool saved = writer.write("measurements.csv", array);
25 * @endcode
26 *
27 * For large arrays, call open(), write_rows() with bounded slices,
28 * and close(). Every slice must use the layout passed to open().
29 */
