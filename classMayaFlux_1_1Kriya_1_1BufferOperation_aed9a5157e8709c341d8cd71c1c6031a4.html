static

Route many GPU images into the layers of a texture array buffer.

Each cycle images[i] is copied into layer i on the GPU, and the array buffer fits it to the layer. An image that stays the same object is copied again with whatever it holds that cycle.

Parameters
targetArray buffer that receives the frames.
imagesOne image per layer, in layer order.
