Detailed Description

What VisionWorkflow::process_to_stream() runs: the stream to analyze, the matrix that analyzes it, the layer array the Chimera feeds, the images recorded over time, and optionally how the run is paced.

layers gives the array's width, height, format and, as ring_frames, its layer count. fit places images of another extent in a layer.

Each record entry appends what its picker returns to its collection when an analysis completes, so the collection holds only finished frames. Read it in a layer with ChimeraBuilder::from(collection, frame_rate) for lag, speed and cut, or at lag zero for the newest frame of every layer changing together.
