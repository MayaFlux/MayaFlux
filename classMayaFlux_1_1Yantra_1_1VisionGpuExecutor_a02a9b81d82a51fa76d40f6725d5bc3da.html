2D Gaussian kernel for convolution, cached by (radius, sigma bit pattern).

Sigma is a tuning parameter that rarely changes frame to frame; recomputing exp() over (2*radius+1)^2 taps and reallocating the kernel every call is pure repeated work for an identical result.

Parameters
radiusRadius of the kernel in pixels. Kernel size is (2*radius + 1)^2.
sigmaStandard deviation of the Gaussian.
Returns
Normalized kernel weights as a flat vector in row-major order.
