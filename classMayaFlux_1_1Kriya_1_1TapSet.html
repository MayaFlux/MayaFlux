Detailed Description

One stream read by several independent taps.

Like several samplers sharing a stream, each tap has its own entry time, speed, direction, level and output channels. Made by TapSetBuilder::start(). Taps are numbered in the order they were declared. Copies share the same taps, so keep one alive for as long as the set should sound.
