static

Allocate zeroed pixel storage of the variant format calls for.

The variant matches what is_consistent() expects: uint8 for the 8-bit formats, uint16 for the 16-bit and half-float formats, float for the 32-bit float formats. Holds width * height * channels elements.

Returns
The sized ImageData, or nullopt when any dimension or the channel count is zero, or the format has no storage mapping.
