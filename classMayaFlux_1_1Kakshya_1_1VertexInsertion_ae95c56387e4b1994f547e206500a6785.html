bool MayaFlux::Kakshya::VertexInsertion::insert_interleaved ( std::span< const uint8_t >  vertex_bytes,
const VertexLayout &  layout 
)

Replace the channel list with the attributes of interleaved vertices.

The vertex count is derived from the byte count, not from layout.vertex_count, so a layout describing capacity cannot over-read.

Parameters
vertex_bytesInterleaved vertices; size must be a nonzero multiple of layout.stride_bytes.
layoutAttribute offsets and stride of vertex_bytes.
Returns
False, with an error logged and the channel list untouched, when the layout or byte count is invalid.
