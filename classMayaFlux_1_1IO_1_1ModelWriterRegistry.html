Detailed Description

Singleton registry dispatching model writes by file extension.

Mirrors ImageWriterRegistry/VolumeWriterRegistry. Concrete writers register themselves during subsystem init. create_writer(path) looks up the extension and returns a fresh instance, or nullptr if none is registered.
