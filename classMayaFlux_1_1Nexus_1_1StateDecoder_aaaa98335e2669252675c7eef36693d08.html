Decode and apply to fabric.

Parameters
fabricTarget fabric. Must already contain entities with ids matching the schema. Expanses are restored too; one that matches an Expanse already on the Fabric is left in place and only has its box updated.

Returns
True on success. Partial patches (some ids missing) still return true; failures are logged.
