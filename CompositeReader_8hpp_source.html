12/**
13 * @class CompositeReader
14 * @brief Typed FileReader boundary for schema-bearing Composite data.
15 *
16 * Concrete readers return CompositeArray values without flattening their
17 * layout or text storage into unrelated DataVariant channels. The inherited
18 * DataVariant and SignalSourceContainer result methods are unsupported.
19 * get_layout() exposes the schema a concrete reader established on open(),
20 * so a caller can inspect field names and types before reading any data.
21 *
22 * Usage:
23 * @code
24 * std::unique_ptr<CompositeReader> reader =
25 * std::make_unique<DelimitedTextReader>();
26 * if (reader->open("measurements.csv")) {
27 * auto first = reader->read_next(1024);
28 * auto remaining = reader->read_composite();
29 * }
30 * @endcode
31 *
32 * @note read_composite() reads from the current position. Call seek({0})
33 * first to read the complete file after earlier bounded reads.
