Target that pushes an influence's value to a GPU executor as push constants.

Template Parameters
TTrivially copyable struct matching the shader's push constant layout.
Parameters
targetAn operator with push_constants (MeshFieldOperator, InstanceFieldOperator) or a shader processor with set_push_constant_data; raw pointer or shared_ptr, retained by the target.

For an operator this arms the next dispatch of its executor. This is how an Agent's state reaches a slot-transform kernel, for example one assembled from a DualField of mat4 through ShaderSpec::Assemble::function(). For a shader processor the push block is grown to hold T at offset here, so a shader that already declares it is not drawn before the block exists. A shader that keeps push constants of its own passes the byte offset after them and declares both in one block.
