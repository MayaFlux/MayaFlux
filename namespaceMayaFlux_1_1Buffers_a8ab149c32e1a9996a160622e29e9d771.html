MAYAFLUX_API std::optional< Kakshya::MeshData > MayaFlux::Buffers::download_compute_mesh ( const std::shared_ptr< ComputeMeshBuffer > &  buffer)

Download a ComputeMeshBuffer's current live geometry to CPU.

One-shot and blocking, via download_from_gpu_async: call it off the graphics thread. Downloads exactly ComputeMeshBuffer::get_live_vertex_count() vertices rather than the worst-case allocation.

Parameters
bufferSource buffer. setup_processors() must have run.
Returns
The geometry as non-indexed triangles, or nullopt if the buffer is null, has no readable counter, or the live vertex count is zero.
