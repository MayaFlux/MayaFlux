Build a relaxation grid seeded from a host callable.

Parameters
configGrid arrangement.
seedCallable taking cell coordinates (x, y) and returning the cell's state. x runs over [0, width) and y over [0, height).
renderRender target. target_window is required.
Returns
The registered grid, or nullptr if the target window is null or the seed's return type does not match the grid's cell stride.

The seed's return type is the cell type, constrained by GridCellData and checked against the stride the config resolved. The state is written before registration, so the first generation steps from it.
