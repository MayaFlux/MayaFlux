One explicit step of generalised Lotka-Volterra competition.

Parameters
levelsNonnegative levels, updated in place
growthGrowth rate of each level
interactionRow-major N x N matrix; entry (i, j) is how strongly level j suppresses level i, the diagonal being self limitation
dtStep

Each level changes by dt * a_i * (growth_i - sum_j interaction_ij * a_j), all from the levels at the start of the step, then is held at zero or above. With suppression stronger between entries than within them, the levels take turns instead of settling together. Does nothing when the interaction matrix is smaller than N x N. Uses a per-thread scratch vector, so it allocates only the first time a size is seen.
