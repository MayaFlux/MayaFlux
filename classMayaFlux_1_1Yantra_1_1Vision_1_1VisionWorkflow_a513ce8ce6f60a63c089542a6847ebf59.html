std::shared_ptr< Buffers::TextureBuffer > MayaFlux::Yantra::Vision::VisionWorkflow::process_to_buffer ( const WorkflowBufferConfig &  config)

Run config's query on its source live and show what its extraction takes from each frame in a texture buffer.

The stream is hooked to a buffer unless it already has one. Without a live config, or with an interval of zero, the work sets the pace: the analysis advances one sequence per graphics tick without waiting on deferred flow steps. A stream that is not looping stops the run at its end. The output buffer takes the source's size, or the apply_to buffer's when one is set.

Returns
The output buffer, or null with a logged reason when the engine's managers are gone or the stream cannot be hooked.
